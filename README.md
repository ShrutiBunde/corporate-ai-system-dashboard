# Corporate AI System Dashboard

**Internship Project** | Microsoft Power BI

| | |
|---|---|
| **Project** | Corporate AI System Dashboard |
| **Role** | Data Analyst Intern |
| **Domain** | CRM & Business Intelligence |
| **Tool** | Microsoft Power BI |

End-to-end CRM analytics dashboard with 5 interactive pages covering the complete customer lifecycle — from lead generation to revenue.

---

## Overview

This project was developed as part of internship work. The goal was to design and build a professional Power BI dashboard that gives clear visibility into:

- Lead acquisition and quality  
- AI & call performance  
- Follow-up discipline  
- Appointment conversion  
- Revenue and customer health  

The dashboard uses a multi-table synthetic CRM dataset and follows a consistent design system across all pages.

---

## Dashboard Pages

| # | Page | Focus |
|---|------|-------|
| 1 | **Executive Overview** | High-level business KPIs, lead trends, conversion funnel, revenue overview |
| 2 | **Lead Performance** | Lead quality, score distribution, temperature, source quality, pipeline movement |
| 3 | **AI & Call Performance** | AI interactions, resolution rate, response time, handoffs, call outcomes |
| 4 | **Follow-up & Appointments** | Follow-up status, overdue items, appointment show rate and conversion |
| 5 | **Revenue & Customers** | Revenue trends, payment status, customer health, top customers, recurring revenue |

---

## Features

- Consistent dark sidebar navigation across all pages  
- KPI cards with key metrics on every page  
- Interactive charts (line, column, bar, donut, funnel, matrix, table, gauge)  
- Global date range filter + additional slicers  
- Reset button (Clear all slicers)  
- Cross-filtering between visuals  
- Actionable tables (High-Priority Leads, Overdue Follow-ups, Top Customers)  

---

## Tech Stack

- **Tool:** Microsoft Power BI Desktop  
- **Language:** DAX (measures & calculated columns)  
- **Data Source:** Multi-table Excel dataset (synthetic / demo data)  
- **Visuals:** Card, Line, Column, Bar, Donut, Funnel, Matrix, Table, Gauge

## How to Open

1. Install [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/)  
2. Open `dashboard/corporate_AI_System_Dashboard.pbix`  
3. All 5 pages will load and are ready for interaction  

To refresh data (if needed):  
- Update the Excel file path in Power BI if required  
- Click **Home → Refresh**
